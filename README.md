# Эмулятор оболочки ОС - вариант 30, этап 2

Минимальный GUI-прототип на Python и `tkinter`. Большое поле показывает
историю диалога и прокручивается, нижнее поле принимает команду, а кнопка `>`
и клавиша Enter запускают ее.

## Требования

- Python 3.10 или новее;
- стандартный модуль `tkinter`.

В Windows `tkinter` обычно входит в стандартную установку Python. На Linux
может понадобиться пакет `python3-tk`.

## Запуск

Windows:

```text
run.bat
```

Любая система с Python:

```text
python -m src.main
```

Linux/macOS:

```text
./run.sh
```

## Параметры запуска

```text
python -m src.main --vfs path/to/vfs.xml --script scripts/startup.txt
```

- `--vfs` - путь к физическому расположению VFS;
- `--script` - путь к стартовому скрипту команд эмулятора.

При запуске оба параметра выводятся в журнале приложения. Стартовый скрипт
выполняется последовательно: каждая строка показывается как ввод и вывод,
ошибочные строки сообщаются и пропускаются.

После ошибки выполнение продолжается. В конце выводится
`Где то в вашем скрипте ошибка`, после чего можно вводить команды вручную.
Если в скрипте уже была ошибка, последующие `exit` не закрывают приложение
и не прерывают оставшиеся команды. В интерактивном вводе `exit` работает
как обычно.

Примеры запуска на Windows: `scripts\\stage2_basic.bat` и
`scripts\\stage2_errors.bat`. Для Linux/macOS предусмотрены одноименные
скрипты с расширением `.sh`.

## Сборка

Проект использует только стандартную библиотеку Python и не требует отдельной
сборки. При необходимости исходный код можно проверить компиляцией в байт-код:

```text
python -m compileall -q src tests
```

Созданные каталоги `__pycache__` исключены из репозитория через `.gitignore`.

В заголовке окна отображается имя VFS `vfs_stage1`. На первом этапе VFS еще
не подключается, поэтому `ls` и `cd` являются командами-заглушками: они
выводят свое имя и переданные аргументы.

## Поддерживаемые команды

- `ls [аргументы]` - заглушка команды просмотра каталога;
- `cd [аргументы]` - заглушка команды смены каталога;
- `exit` - закрывает приложение.

На втором этапе `ls` и `cd` по-прежнему являются заглушками. Реальная работа
с VFS появляется на этапах 3 и 4.

Парсер поддерживает раскрытие переменных окружения реальной ОС в формах
`$NAME` и `${NAME}`. Если в Windows отсутствует `HOME`, для `$HOME`
используется значение `USERPROFILE`. Клавиши Up/Down возвращают команды из
истории сеанса.

## Сценарий демонстрации

Введите команды по очереди:

```text
ls
ls -la documents
cd $HOME
cd "$HOME/My Documents"
cd $USERPROFILE
unknown
exit now
"незакрытая строка
exit
```

Ожидаемый результат:

- `ls` и `cd` печатают имя команды и аргументы;
- переменная `$HOME` раскрывается из окружения ОС;
- неизвестная команда, лишние аргументы для `exit` и ошибка кавычек
  выводятся сообщениями об ошибке;
- `exit` закрывает окно.

Пример интерактивного диалога; имя пользователя, хоста и домашнего каталога
зависят от реальной ОС:

```text
user@host:~$ ls -la documents
ls: заглушка; аргументы: -la documents
user@host:~$ cd $HOME
cd: заглушка; аргументы: /home/user
user@host:~$ unknown
Ошибка: неизвестная команда 'unknown'.
user@host:~$ exit now
Ошибка: команда exit не принимает аргументы.
user@host:~$ exit
```

Запуск модульных тестов:

```text
python -m unittest discover -s tests -v
```
